# repo-succession-kit

I built this as part of my GitHub Developer Program portfolio, and out of my own history: I have lived an account succession, and I know the question every reader asks afterward. Is this really the same builder? This kit verifies and documents repository succession between two GitHub accounts. It checks commit lineage across the move, separates the identity eras in a history, and builds a succession proof index that any reader can verify line by line, without taking anyone's word for it.

Status: scaffold. The interface is defined and the verification engine is the next build step.

## What it will do

- Compare commit lineage between the old and new homes of a repository
- Separate a history into identity eras, by author identity and date
- Build a succession proof index that ties each claim to a checkable commit
- State plainly what the evidence proves, and what it does not
